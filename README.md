# MiniMapPrint

行きたい場所の地図を、感熱プリンタで刷れる小さな一枚に。

地名や住所を入れるだけで、ポケットに入るサイズの地図をブラウザで生成します。出力はプリンタのドット数にぴったり合わせた1ビット PNG。線画とグレーの2スタイルを並べて見比べて、気に入った方を印刷できます。

**▶ 使ってみる: https://tanep3.github.io/MiniMapPrint/**

## できること

- ランドマークを1つ（または2つ）指定して地図を生成
- 縮尺は 100m〜5km をスライダーで切り替え（近所だけの地図も作れます）
- 原画マップの上でドラッグやピンチで表示位置を微調整できるので、住所検索で中心が合わない場所でもぴったりの範囲で印刷できます
- 現在地ボタンで、今いる場所の地図をそのまま生成
- 線画スタイルと、写真のような階調のグレースタイル（pic2gray4px 変換）
- 200dpi（T02等）と300dpi（M02S等）の出力幅に対応
- スマホの共有から Phomemo アプリへ送って印刷、PC からはそのまま印刷

## 使い方

**▶ https://tanep3.github.io/MiniMapPrint/**

ブラウザで開いて、場所を入れて、地図を作る。それだけです。インストールもアカウントも不要です。

地図データは OpenStreetMap を使っています（© OpenStreetMap contributors / ODbL）。
